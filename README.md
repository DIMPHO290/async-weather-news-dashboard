# async-weather-news-dashboard

🌦️ Weather & News Dashboard

A simple Node.js and TypeScript project that fetches real-time weather data and latest news headlines.
This project demonstrates three asynchronous programming styles in Node.js: Callbacks, Promises, and Async/Await.

✨ Features
🌍 Get current weather by city name
🌡️ Displays temperature, weather description
📰 Fetches latest news headlines
⚡ Demonstrates callback, promise, and async/await async patterns
🛠️ Built with TypeScript for type safety

🛠️ Technologies Used
Node.js
TypeScript
Axios / HTTPS (for API requests)
Dotenv (for environment variables)
OpenWeather API (weather data)
MediaStack API (news data)

⚙️ Setup Instructions
Clone the repository:
git clone https://github.com/DIMPHO290/node-weather-news-dashboard.git
cd node-weather-news-dashboard
npm install
npm run start:callback
npm run start:promise
npm run start:async

### How add the AIP KEY to env file

-create the .env file
-VITE_WEATHER_API_KEY= "USE_YOUR_API_KEY"
-VITE_NEWS_API_KEY = "USE_YOUR_API_KEY"
